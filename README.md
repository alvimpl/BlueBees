# Blue Bees

App de acompanhamento dos servidores oficiais do **ARK: Survival Ascended**,
feito para a tribo Blue Bees.

## Baixar

O download está em **[Releases](../../releases/latest)** — o arquivo é o
`BlueBees-Windows.zip`.

Dentro dele há um executável único, sem instalador e sem dependência: descompacte
onde quiser e abra. O app avisa sozinho quando sai versão nova.

Os arquivos "Source code" que o GitHub anexa a toda release contêm apenas este
repositório de distribuição — README, licença e avisos. O código do aplicativo
não fica aqui.

## O que ele faz

- **Servidores** — os oficiais de ASA ao vivo, com filtros, favoritos e o tempo
  real que cada um está no ar
- **Estatísticas** — quem está há mais tempo no ar, quem caiu, os mais cheios e
  os mundos mais antigos
- **Codex** — doma, receitas, criação de filhote, cocho, traits e o gerador de
  arte de negociação

## Idiomas

Português, inglês, espanhol, francês, alemão, polonês, japonês e chinês.
